News Post Migrator — legacy JSON → bilingual (teaser + details)

Mode: Single post. Paste exactly one post object on the left, e.g. { "id": "...", "title": "...", "content": "..." }.
Defaults: teaser is auto-generated (≈ < 100 words) from content_en or legacy content. If content_de is empty and no custom DE is given, it will reuse legacy content.
Ctrl+Enter converts. Output copies on click.
