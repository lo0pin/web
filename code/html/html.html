HTML – ausführliche Anleitung & Cheatsheet

HTML steht für HyperText Markup Language und ist die Auszeichnungssprache, mit der die Struktur einer Webseite beschrieben wird. HTML sagt dem Browser nicht primär, wie etwas aussehen soll, sondern was etwas ist: eine Überschrift, ein Absatz, ein Link, ein Bild, eine Navigation, ein Formularfeld, ein Artikel oder eine Tabelle.

Das Zusammenspiel moderner Webseiten lässt sich grob so zusammenfassen: HTML beschreibt die Struktur, CSS gestaltet die Darstellung und JavaScript steuert Verhalten und Logik.

HTML ist keine Programmiersprache im engeren Sinn. Es enthält keine Schleifen, Variablen oder Funktionen. HTML beschreibt Dokumente und deren semantische Struktur. Der Browser liest dieses Dokument ein und erzeugt daraus das DOM – Document Object Model, auf das anschließend CSS und JavaScript zugreifen können.

Eine robuste Webseite beginnt fast immer mit gut strukturiertem HTML. Wenn die Struktur stimmt, werden CSS und JavaScript deutlich einfacher.

Grundprinzip von HTML

HTML beschreibt Bedeutung

Ein HTML-Dokument besteht aus Elementen. Diese Elemente geben dem Browser und anderen Programmen Informationen über die Bedeutung des Inhalts. 

<h1>Meine Webseite</h1>

<p>
  Das ist ein normaler Absatz.
</p>

<a href="about.html">Über mich</a>

Der Browser erkennt dadurch:

  • <h1> = Hauptüberschrift
  • <p> = Absatz
  • <a> = Link

HTML, CSS und JavaScript

Die drei Kerntechnologien des Webs erfüllen unterschiedliche Aufgaben.

Technologie Aufgabe
HTML Struktur und Bedeutung
CSS Layout und Gestaltung
JavaScript Verhalten und Logik

Wenn du mit HTML versuchst, Abstände oder Farben zu erzeugen, oder mit CSS versuchst, Dokumentstruktur zu ersetzen, kämpfen die Technologien gegeneinander.

Vom HTML zum DOM

Der Browser liest das HTML ein und baut daraus einen Baum von Objekten: das Document Object Model. 

html
├── head
└── body
    ├── header
    ├── main
    │   ├── section
    │   └── article
    └── footer

JavaScript kann diese Elemente anschließend finden, verändern, hinzufügen oder entfernen.

Grundstruktur eines HTML-Dokuments

Minimales HTML5-Dokument

<!DOCTYPE html>
<html lang="de">

<head>
  <meta charset="UTF-8">
  <meta
    name="viewport"
    content="width=device-width, initial-scale=1.0"
  >

  <title>Meine Webseite</title>
</head>

<body>

  <h1>Hallo Welt</h1>

</body>

</html>

Das ist ein sinnvoller Ausgangspunkt für praktisch jede normale HTML-Datei.

<!DOCTYPE html>

Der DOCTYPE steht ganz am Anfang des Dokuments. 

<!DOCTYPE html>

Er signalisiert dem Browser, dass modernes HTML verwendet wird. Ohne DOCTYPE kann ein Browser in den sogenannten Quirks Mode wechseln und ältere Darstellungsregeln verwenden.

<html>

Das <html>-Element umschließt das gesamte Dokument. 

<html lang="de">
  ...
  </html>

Mit lang="de" wird die Sprache des Dokuments angegeben. Das hilft unter anderem Screenreadern, Suchmaschinen und Übersetzungsfunktionen.

<head> und <body>

Das Dokument besteht im Wesentlichen aus zwei Bereichen. 

<head>
  Metadaten, CSS, Seitentitel ...
</head>

<body>
  Sichtbarer Seiteninhalt ...
</body>

Im <head> stehen Informationen über das Dokument. Im <body> steht der eigentliche Inhalt.

Elemente, Tags und Inhalte

Normales Element

<p>Hallo Welt</p>

Dieses Element besteht aus:

  • öffnendem Tag: <p>
  • Inhalt: Hallo Welt
  • schließendem Tag: </p>

Leere Elemente

Manche Elemente besitzen keinen Inhalt und benötigen daher keinen schließenden Tag. 

<img src="bild.jpg" alt="Beschreibung">

<br>

<hr>

<meta charset="UTF-8">

<input type="text">

Schreibweisen wie <br /> funktionieren ebenfalls, der Slash ist in HTML5 aber nicht erforderlich.

Groß- und Kleinschreibung

HTML-Tagnamen sind grundsätzlich nicht case-sensitive. 

<P>Text</P>

<p>Text</p>

Trotzdem sollte modernes HTML konsequent kleingeschrieben werden.

Einheitlichkeit spart später erstaunlich viel geistigen Kleinkrieg.

Attribute

Was Attribute sind

Attribute ergänzen ein HTML-Element um zusätzliche Informationen. 

<a
  href="about.html"
  class="button"
  title="Über mich"
>
  About
</a>

Hier besitzt das Element drei Attribute: href, class und title.

Typische Attribute

Attribut Bedeutung
class Zuordnung zu einer oder mehreren CSS-/JS-Klassen
id Eindeutige Kennung innerhalb der Seite
href Ziel eines Links
src Quelle einer Ressource
alt Alternativtext eines Bildes
title Zusätzliche Information
lang Sprache des Elements
hidden Element ausblenden

Boolean-Attribute

Einige Attribute benötigen keinen eigenen Wert. Ihre bloße Anwesenheit bedeutet bereits „aktiv“. 

<input type="checkbox" checked>

<input type="text" required>

<button disabled>
  Nicht verfügbar
</button>

<script src="main.js" defer></script>

Verschachtelung

Elemente korrekt verschachteln

HTML-Elemente können andere Elemente enthalten. Dabei sollte die Verschachtelung sauber geschlossen werden. 

<p>
  Das ist
  <strong>sehr wichtig</strong>.
</p>

Falsch:

<p>
  Das ist
  <strong>sehr wichtig.
</p>
</strong>

Browser versuchen fehlerhaftes HTML oft automatisch zu reparieren. Das ist hilfreich, sollte aber nicht als Programmiertechnik missverstanden werden.

Einrückung

<section>
  <h2>Astronomie</h2>

  <article>
    <h3>Der Mond</h3>
    <p>Unser natürlicher Satellit.</p>
  </article>
</section>

Die Einrückung verändert das Ergebnis im Browser normalerweise nicht, macht die Struktur für Menschen aber erheblich verständlicher.

Kommentare

HTML-Kommentare

<!-- Das ist ein Kommentar. -->

Kommentare werden im Browser nicht als sichtbarer Seiteninhalt dargestellt. 

<!-- Navigation -->
<nav>
  ...
</nav>

<!-- News werden hier per JavaScript geladen -->
<div data-news-mode="latest"></div>

Kommentare sind gut für Struktur und ungewöhnliche Entscheidungen. Sie sollten aber nicht jede offensichtlich verständliche HTML-Zeile paraphrasieren.

Code temporär deaktivieren

<!--
<a href="old-page.html">
  Alte Seite
</a>
-->

Für kurze Tests ist das praktisch. Große Mengen auskommentierten Alt-Codes gehören langfristig jedoch eher in Git als mitten ins Dokument.

Text und Überschriften

Überschriften h1 bis h6

<h1>Astronomie</h1>

<h2>Sonnensystem</h2>

<h3>Planeten</h3>

<h4>Innere Planeten</h4>

<h5>Erde</h5>

Überschriften erzeugen eine logische Dokumenthierarchie. Sie sollten aufgrund ihrer Bedeutung gewählt werden, nicht aufgrund der gewünschten Schriftgröße.

Die Größe einer Überschrift wird mit CSS geändert. HTML entscheidet über ihre hierarchische Bedeutung.

Das <h1>

Das <h1> bezeichnet üblicherweise die wichtigste Überschrift der Seite. 

<main>
  <h1>Der Mond</h1>


  <section>
    <h2>Entstehung</h2>
  </section>

  <section>
    <h2>Geologie</h2>
  </section>
</main>

Absätze mit <p>

<p>
  HTML beschreibt die Struktur eines Dokuments.
</p>

<p>
  CSS übernimmt dessen visuelle Gestaltung.
</p>

Inhaltlich getrennte Gedanken sollten auch als getrennte Absätze ausgezeichnet werden.

Zeilenumbruch <br>

<p>
  Musterstraße 10<br>
  8010 Graz<br>
  Österreich
</p>

<br> erzwingt einen Zeilenumbruch. Es sollte für echte Zeilenumbrüche verwendet werden, etwa bei Adressen oder Gedichten – nicht als Ersatz für CSS-Abstände.

Thematische Trennung mit <hr>

<hr class="divider">

<hr> bedeutet semantisch eine thematische Zäsur. Dass daraus meist eine horizontale Linie wird, ist die Standarddarstellung.

Zitatblock <blockquote>

<blockquote>
  <p>
    Der Himmel ist nicht weniger tief,
    nur weil wir ihn vermessen.
  </p>
</blockquote>

Für längere Zitate ist <blockquote> semantisch besser geeignet als ein gewöhnlicher Absatz.

Wichtige Inline-Elemente

<strong>

Kennzeichnet starke inhaltliche Bedeutung oder Wichtigkeit. 

<p>
  Diese Spannung ist
  <strong>lebensgefährlich</strong>.
</p>

<em>

Kennzeichnet Betonung. 

<p>
  Das ist <em>wirklich</em> wichtig.
</p>

<b> und <i>

<b> und <i> können verwendet werden, wenn eine visuelle oder typografische Absetzung gemeint ist, aber keine stärkere semantische Bedeutung.

Für echte Wichtigkeit und Betonung sind <strong> und <em> meist die bessere Wahl.
