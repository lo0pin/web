HTML Links are defined with the < a> tag
for example: < a href="www.bulme.at">here comes the text< /a>

however, images are defined via the < img> tag.
an example: < img scr="https://images.pexels.com/photos/1266884/pexels-photo-1266884.jpeg" alt= "oh what a picture" width ="12" heigth="34">
note:
absolute URLs link to an external site or image
like: src="www.bulme.at/picture.jpg"
whereas relative URLs link to an image, which is hosted within the website
like: src="picture_of_penguins.jpg" (if the URL beginns with a slash, it will be relative to the domain: src:"/images/penguins_with_hats.jpg")
preferably relatives URLs are used, so they won't break, if e.g. the domain is changed.

Linux Cheatsheet

Command Explaination
ls [-l] [-a] lists content of directory
pwd prints working directory
cd [path] changes directory (cd alone: switch to home directory)
cd .. move a level up (directory)
cd ~ change to home directory
cd - change to previous directory
cd / change to root directory
cp [-r] [source] [target] copies files (for directories use -r; folders in Linux end with a slash /)
rm [-r] [-f] remove files and directories (for empty directories use -r, for directories with content use -rf)
mv [source] [target] moves/renames files and directories
mkdir [name] creates directories
touch [name] creates file
man displays manual page for commands
chmod changes file permissions
chmod 753 public_html rights are given in groups of three - each meaning Read, Write, eXecute
the groups are: owner, group, others
7 = 111 in binary, 5=101, 3=001
owner can rwx, group can r_x, others can x
chmod o+r all others can Read
sudo execute commands as superuser
apt-get get files from the internet using the apt-packagemanager
exit exit the current shell session
shutdown [now] shuts the machine down (default is 1 Minute)
echo displays lines of text
passwd change user password
shred overwrites file to hide its contents
less inspects file's contents
head/tail displays first/last lines of a file
whoami outputs username
whatis one-lined description
su [user] switch user to [user]
Ctrl + D End of input
apt install [name] install software
sudo apt update && apt upgrade updates and upgrades installed software
./ current directory (e.g. for cp)
f4
history shows a list of previously used commands
which outputs the full path of shell commands
e.g. which python --> #/usr/bin/python
grep ["expression"] [file] searches txt files for regular expressions
grep "linux" file.txt --> searches file.txt for "linux"
[command] --help outputs help for the command
su - switch user with login-shell
apt install installs programm from APT
apt search sort of search enginge for APT
CTRL+D end of input
ALT+. resuse last expression from last input
htop view machine's resources
sudo apt install [name] installs program [name]
$User current User
cat concatenate files
kill [e.g. firefox] terminates processes
ping [e.g. orf.at] test network connectivity
passwd change password
