JavaScript — vom ersten Wert bis zur soliden Webanwendung

JavaScript macht aus einer statischen Webseite ein Programm. HTML beschreibt, was vorhanden ist, CSS bestimmt, wie es aussieht, und JavaScript entscheidet, was geschieht: Elemente reagieren auf Klicks, Daten werden geladen, Inhalte gefiltert, Formulare geprüft und Zustände gespeichert.

Dieser Guide beginnt bewusst bei null und führt schrittweise zu Themen, mit denen du bereits robuste, gut strukturierte Anwendungen im Browser bauen kannst. Die Beispiele verwenden modernes JavaScript ohne Frameworks, Build-Tools oder externe Bibliotheken — passend für eine statische GitHub-Pages-Webseite.

Merksatz: HTML liefert die Elemente. CSS gestaltet sie. JavaScript liest Zustände, trifft Entscheidungen und verändert die Seite.

So verwendest du diesen Guide als Anfänger

Du musst nicht alles auf einmal verstehen

Arbeite zunächst bis zu Arrays, Objekten und Funktionen. Danach baust du etwas Kleines mit DOM und Events. Asynchroner Code, Module, Prototypen und Event Loop werden erst wichtig, wenn die Grundlagen nicht mehr bei jedem Semikolon knirschen.

Die wichtigsten Zeichen lesen

const name = "Julian"; // = weist einen Wert zu
greet(name);           // () ruft eine Funktion auf
user.name;             // . greift auf eine Eigenschaft zu
items[0];              // [] greift auf einen Index zu
if (ready) {           // {} bilden einen Codeblock
  start();
}

JavaScript unterscheidet Groß- und Kleinschreibung: postTitle und posttitle sind zwei verschiedene Namen.

Dein erstes sichtbares Mini-Programm

<button id="hello" type="button">Begrüßen</button>
<p id="output"></p>

<script src="hello.js" defer></script>
// hello.js
const button = document.querySelector("#hello");
const output = document.querySelector("#output");

button.addEventListener("click", () => {
  output.textContent = "Hallo aus JavaScript!";
});

Ändere danach Text, Selektor oder Event absichtlich. Aus Nachbauen wird Lernen, sobald du an einer Stelle selbst den Kurs bestimmst.

Bei Fehlern zuerst in die Konsole

Öffne die Entwicklerwerkzeuge mit F12 und wähle „Konsole“. Die erste rote Meldung ist meist wichtiger als alle Folgefehler. Klicke auf Datei und Zeilennummer, statt den Code auf gut Glück umzurühren.

1. Das mentale Modell: Was JavaScript eigentlich tut

Der Browser lädt HTML, baut daraus den DOM-Baum, verarbeitet CSS und führt JavaScript aus. JavaScript arbeitet dabei in einer Laufzeitumgebung. Im Browser gehören etwa document, window, fetch() und localStorage zur Umgebung; sie sind keine Bestandteile der reinen Sprache.

Sprache und Browser-API unterscheiden

Variablen, Funktionen, Arrays und Klassen gehören zu JavaScript. document.querySelector() gehört zum DOM und damit zur Browser-API. 

// Reines JavaScript
const doubled = [1, 2, 3].map(number => number * 2);

// Browser-API
const heading = document.querySelector("h1");
heading.textContent = doubled.join(", ");

Derselbe JavaScript-Code findet in unterschiedlichen Umgebungen unterschiedliche Schnittstellen vor.

Code läuft grundsätzlich von oben nach unten

Synchrone Anweisungen werden der Reihe nach ausgeführt. Asynchrone Arbeit wird angestoßen und später fortgesetzt. 

console.log("A");

setTimeout(() => {
  console.log("C");
}, 0);


console.log("B");
// Ausgabe: A, B, C

Eine Verzögerung von 0 Millisekunden bedeutet nicht „sofort“, sondern „frühestens, wenn der aktuelle Code fertig ist“.

JavaScript ist dynamisch typisiert

Werte besitzen Typen, Variablen jedoch keine dauerhaft festgelegten. Eine Variable kann später einen Wert eines anderen Typs halten — erlaubt, aber oft ein Eigentor. 

let value = 42;
value = "jetzt ein String"; // erlaubt

// Besser: klare, stabile Bedeutung
const temperatureCelsius = 24.6;

Der Browser ist ereignisgetrieben

Viel JavaScript wartet auf Ereignisse: Klicks, Eingaben, geladene Daten, Timer oder Größenänderungen. 

const button = document.querySelector("#save");

button.addEventListener("click", () => {
  console.log("Speichern wurde angefordert.");
});

2. JavaScript einbinden und sinnvoll starten

Externe Datei mit defer

Für klassische Skripte ist defer meist die vernünftige Wahl. Die Datei wird parallel geladen und erst ausgeführt, nachdem das HTML geparst wurde. 

<script src="assets/js/main.js" defer></script>

Externe Dateien sind übersichtlicher, wiederverwendbar und leichter zu cachen als lange Inline-Skripte.

ES-Module mit type="module"

Module erlauben import und export. Sie werden automatisch verzögert ausgeführt und verwenden einen eigenen Gültigkeitsbereich. 

<script type="module" src="assets/js/news.js"></script>

Für neuen, auf mehrere Dateien verteilten Code sind Module der sauberste Standard.

Inline-JavaScript nur für Kleinstfälle

<script>
  console.log("Die Seite läuft.");
</script>

Ein kleiner Test ist legitim. Dauerhafte Anwendungslogik zwischen HTML-Tags wird aber rasch unübersichtlich.

Nicht über file:// testen

Module und fetch() benötigen normalerweise einen Webserver. Öffne die Datei deshalb nicht bloß per Doppelklick. 

# Im Projektordner:
python -m http.server 8000


# Danach im Browser:
http://localhost:8000

Ein lokaler Server verhält sich wesentlich ähnlicher wie GitHub Pages und verhindert rätselhafte CORS- und Pfadfehler.

Wann braucht man DOMContentLoaded?

Bei einem korrekt eingebundenen defer- oder Modulskript normalerweise gar nicht. Das DOM ist dann bereits geparst. Bei einem klassischen Skript im <head> ohne defer wäre es hingegen zu früh, darunterliegende Elemente abzufragen.

3. Syntax, Kommentare und die Entwicklerkonsole

Anweisungen und Blöcke

Eine Anweisung erledigt einen Schritt. Geschweifte Klammern bündeln mehrere Anweisungen zu einem Block. 

const isReady = true;

if (isReady) {
  console.log("Start");
  console.log("Alles bereit");
}

Semikolons sind häufig automatisch ergänzbar. Konsistente Semikolons vermeiden aber einige seltene, dafür besonders boshafte Mehrdeutigkeiten.

Kommentare

Kommentare erklären Absicht, Randbedingungen oder überraschende Entscheidungen. Sie sollten nicht wiederholen, was der Code ohnehin sagt. 

// Einzeiliger Kommentar

/*
  Mehrzeiliger Kommentar
*/


const retryLimit = 3; // Mehr Versuche würden nur den Server belasten.

Die Konsole gezielt verwenden

console.log("Allgemeine Ausgabe");
console.info("Information");
console.warn("Auffälliger Zustand");
console.error("Fehler");
console.table([
  { title: "HTML", done: true },
  { title: "JavaScript", done: false }
]);

Strikter Modus

"use strict" verhindert manche stillen Altlasten. ES-Module laufen automatisch im strikten Modus. 

"use strict";

// Fehler statt heimlicher globaler Variable:
accidentalGlobal = 42;

4. Variablen: const, let und das historische var

const als Standard

const verhindert, dass der Variable später ein anderer Wert zugewiesen wird. Das macht Absichten klar und Code leichter nachvollziehbar. 

const siteTitle = "Julian";
const maxPosts = 3;

// maxPosts = 5; // TypeError

Verwende const, solange du nicht konkret weißt, dass eine Neuzuweisung nötig ist.

let für echte Veränderung

let currentIndex = 0;
currentIndex += 1;

let status = "loading";
status = "ready";

const macht Objekte nicht unveränderlich

const settings = { language: "de" };
settings.language = "en"; // erlaubt

const tags = ["code"];
tags.push("javascript"); // erlaubt

Für eine flache Sperre gibt es Object.freeze(). Verschachtelte Objekte werden dadurch nicht automatisch eingefroren.

var in neuem Code meiden

var besitzt Funktions- statt Block-Scope und verhält sich beim Hoisting überraschend. Es bleibt für alten Code wichtig, ist aber kein moderner Standard. 

if (true) {
  var oldStyle = "außerhalb sichtbar";
  let modernStyle = "nur im Block sichtbar";
}

console.log(oldStyle);
// console.log(modernStyle); // ReferenceError

5. Datentypen und Werte

JavaScript kennt sieben primitive Datentypen: string, number, bigint, boolean, undefined, null und symbol. Alles andere sind Objekte — auch Arrays und Funktionen im weiteren Sinn.

Primitive Werte

const title = "JavaScript";      // string
const temperature = 24.5;       // number
const huge = 9007199254740993n; // bigint
const visible = true;           // boolean
let result;                     // undefined
const selected = null;          // null
const id = Symbol("id");         // symbol

Primitive Werte werden als Werte verglichen. Objekte werden nach ihrer Identität verglichen.

typeof und seine Schrullen

typeof "Hallo";       // "string"
typeof 42;            // "number"
typeof true;          // "boolean"
typeof undefined;     // "undefined"
typeof {};            // "object"
typeof [];            // "object"
typeof (() => {});    // "function"
typeof null;          // "object" — historischer Sprachfehler

Array.isArray([]);    // true

null und undefined

undefined bedeutet meist „noch kein Wert vorhanden“. null wird bewusst gesetzt und bedeutet „absichtlich kein Wert“. 

let response;              // undefined
const selectedPost = null; // bewusst nichts gewählt

Werte und Referenzen

const a = { count: 1 };
const b = a;

b.count = 2;
console.log(a.count); // 2

const c = { count: 2 };
console.log(a === c); // false

6. Typumwandlung, Truthy/Falsy und Gleichheit

Explizit umwandeln

Number("42");         // 42
Number("42px");       // NaN
parseInt("42px", 10); // 42
parseFloat("3.14");   // 3.14
String(42);           // "42"
Boolean(1);           // true
Boolean(0);           // false

Explizite Umwandlung ist fast immer verständlicher als die automatischen Kunststücke der Sprache.

Falsy-Werte

In Bedingungen gelten nur wenige Werte als falsch: false, 0, -0, 0n, "", null, undefined und NaN. 

if ("Hallo") {
  console.log("Nichtleere Strings sind truthy.");
}


if ([]) {
  console.log("Auch leere Arrays sind truthy.");
}

Strikte Gleichheit verwenden

0 === false;  // false
0 == false;   // true — automatische Typumwandlung

"5" === 5;   // false
"5" == 5;    // true

Verwende grundsätzlich === und !==. Lose Gleichheit ist ein Spezialwerkzeug, kein bequemer Standard.

NaN richtig erkennen

const value = Number("Kartoffel");

value === NaN;          // immer false
Number.isNaN(value);    // true
Number.isFinite(value); // false

NaN bedeutet „Not a Number“, besitzt aber paradoxerweise den Typ number. JavaScript hat Sinn für schwarzen Humor.

7. Operatoren, Kurzschlusslogik und moderne Abkürzungen

Rechnen und Zuweisen

const sum = 10 + 5;
const difference = 10 - 5;
const product = 10 * 5;
const quotient = 10 / 5;
const remainder = 10 % 3; // 1
const power = 2 ** 3;      // 8

let count = 1;
count += 2; // 3
count++;    // 4

Vergleiche

5 > 3;     // true
5 >= 5;    // true
3 < 5;     // true
3 <= 2;    // false
5 === 5;   // true
5 !== "5"; // true

Logische Operatoren

const canEdit = isLoggedIn && hasPermission;
const displayName = nickname || "Unbekannt";
const isHidden = !isVisible;

&& und || liefern nicht zwingend Booleans, sondern einen der geprüften Werte.

Nullish Coalescing ??

?? verwendet den Ersatzwert nur bei null oder undefined. Null und leere Strings bleiben gültige Werte. 

const savedLimit = 0;

savedLimit || 10; // 10
savedLimit ?? 10; // 0

Optional Chaining ?.

Optional Chaining bricht sicher ab, wenn ein Zwischenschritt null oder undefined ist. 

const city = user.address?.city ?? "nicht angegeben";
const firstImage = post.images?.[0]?.src;
callback?.();

Verwende es nicht, um eigentlich notwendige Daten still zu verschlucken. Ein echter Datenfehler darf sichtbar werden.

Ternärer Operator

const label = isOnline ? "Online" : "Offline";

Gut für eine kurze Entscheidung. Verschachtelte Ternaries sind meist ein Hilferuf in Satzzeichenform.

Spread und Rest

// Spread: Werte ausbreiten
const allTags = [...baseTags, "javascript"];
const updatedPost = { ...post, title: "Neuer Titel" };

// Rest: übrige Werte einsammeln
const [first, ...remaining] = allTags;

function sum(...numbers) {
  return numbers.reduce((total, number) => total + number, 0);
}

Operatorrangfolge entschärfen

const result = (price * amount) + shipping;
const allowed = isAdmin || (isOwner && isActive);

Klammern kosten fast nichts und ersparen dem Leser das mentale Nachschlagen einer Rangfolgetabelle.

8. Bedingungen und Verzweigungen

if, else if, else

if (temperature < 0) {
  status = "Frost";
} else if (temperature < 20) {
  status = "Kühl";
} else {
  status = "Warm";
}

Früh zurückkehren

Guard Clauses halten den Hauptweg einer Funktion flach und lesbar. 

function renderPost(post) {
  if (!post) return;
  if (!post.title) {
    throw new Error("Der Beitrag benötigt einen Titel.");
  }

  // Hauptlogik ohne tiefe Verschachtelung
}

switch für diskrete Fälle

switch (topic) {
  case "code":
    icon = "💻";
    break;
  case "sailing":
    icon = "🌊";
    break;
  default:
    icon = "📝";
}

Ohne break fällt die Ausführung in den nächsten Fall weiter. Das kann beabsichtigt sein, ist aber häufig schlicht ein Fehler.

Objekt als einfache Zuordnung

const icons = {
  code: "💻",
  sailing: "🌊",
  electronics: "⚡"
};

const icon = icons[topic] ?? "📝";

Bei einer reinen Wertzuordnung ist ein Objekt oft kompakter als ein langer switch.

Strings erzeugen

const single = 'Einfach';
const double = "Doppelt";

Nützliche String-Methoden

const text = "  JavaScript Guide  ";

text.trim();                   // "JavaScript Guide"
text.toLowerCase();            // "  javascript guide  "
text.toUpperCase();

const original = "hallo";

10. Zahlen, Math, Datum und internationale Formatierung

Runden und begrenzen

Math.round(3.6); // 4
Math.floor(3.9); // 3
Math.ceil(3.1);  // 4
Math.trunc(3.9); // 3

const clamped = Math.min(Math.max(value, 0), 100);

Minimum, Maximum und Potenzen

Math.min(3, 8, -2); // -2
Math.max(3, 8, -2); // 8
Math.abs(-7);       // 7
Math.sqrt(81);      // 9
Math.hypot(3, 4);   // 5

Zufallszahlen

// Ganzzahl von min bis einschließlich max
function randomInteger(min, max) {
  return Math.floor(Math.random() * (max - min + 1)) + min;
}

Math.random() ist nicht kryptografisch sicher. Für Sicherheitstokens gibt es crypto.getRandomValues().

Gleitkommazahlen

0.1 + 0.2 === 0.3; // false

const approximatelyEqual =
  Math.abs((0.1 + 0.2) - 0.3) < Number.EPSILON;

Geldbeträge besser in der kleinsten Einheit rechnen, etwa Cent als ganze Zahl.

Zahlen formatieren

const formatter = new Intl.NumberFormat("de-AT", {
  style: "currency",
  currency: "EUR"
});

formatter.format(1234.5); // etwa "1.234,50 €"

Datum erzeugen und formatieren

const now = new Date();
const date = new Date("2026-08-23T12:00:00+02:00");

const formatted = new Intl.DateTimeFormat("de-AT", {
  dateStyle: "long",
  timeStyle: "short",
  timeZone: "Europe/Vienna"
}).format(date);

Ein Datum ohne Zeitzonenangabe ist eine Einladung an subtile Fehler. Speichere Zeitpunkte möglichst als vollständige ISO-Zeitangaben.

Datumskomponenten beachten

const date = new Date();

date.getFullYear();
date.getMonth(); // 0 bis 11
date.getDate();  // Tag des Monats
date.getDay();   // Wochentag: 0 = Sonntag

getDate() und getDay() klingen zum Verwechseln ähnlich. Die Sprache legt hier eine kleine Bananenschale aus.

Zeit messen

const start = performance.now();
doWork();
const duration = performance.now() - start;

console.log(`${duration.toFixed(2)} ms`);

11. Arrays: Listen speichern, verändern und transformieren

Erzeugen und zugreifen

const topics = ["html", "css", "javascript"];

topics[0];             // "html"
topics.at(-1);         // "javascript"
topics.length;         // 3
Array.isArray(topics); // true

Am Anfang und Ende verändern

const items = ["b"];

items.push("c");     // hinten hinzufügen
items.pop();         // hinten entfernen
items.unshift("a"); // vorne hinzufügen
items.shift();       // vorne entfernen

Diese Methoden verändern das ursprüngliche Array. shift() und unshift() sind bei sehr großen Arrays aufwendiger.

slice() versus splice()

const values = ["a", "b", "c", "d"];

const copy = values.slice(1, 3); // ["b", "c"]
// values bleibt unverändert

values.splice(1, 2, "x");
// values ist nun ["a", "x", "d"]

slice kopiert einen Ausschnitt. splice operiert am offenen Herzen des ursprünglichen Arrays.

Suchen und prüfen

posts.includes(selectedPost);
posts.indexOf(selectedPost);
posts.find(post => post.id === wantedId);
posts.findIndex(post => post.id === wantedId);
posts.some(post => post.topic === "code");
posts.every(post => Boolean(post.title));

map(): jeden Wert umformen

const titles = posts.map(post => post.title);

const cards = posts.map(post => ({
  id: post.id,
  label: post.title
}));

map() sollte für jeden Eingangswert genau einen Ausgangswert liefern.

filter(): Werte auswählen

const codePosts = posts.filter(
  post => post.topic === "code"
);

reduce(): Werte zusammenfassen

const topicCounts = posts.reduce((counts, post) => {
  counts[post.topic] = (counts[post.topic] ?? 0) + 1;
  return counts;
}, {});

reduce() ist mächtig, aber nicht automatisch überlegen. Wenn eine verständliche Schleife klarer ist, nimm die Schleife.

Sortieren ohne ungewollte Mutation

const newestFirst = [...posts].sort(
  (a, b) => b.date.localeCompare(a.date)
);

const numbers = [10, 2, 30];
numbers.sort((a, b) => a - b);

sort() verändert das Array und sortiert ohne Vergleichsfunktion als Text. Beides ist eine häufige Fehlerquelle.

Kopien und Verschachtelung

const copy = [...posts];
const objectCopy = { ...post };

// Tiefe Kopie für unterstützte Datentypen:
const deepCopy = structuredClone(data);

Spread kopiert nur die oberste Ebene. Verschachtelte Objekte bleiben dieselben Referenzen.

Flache und kombinierte Arrays

const nested = [[1, 2], [3, 4]];
nested.flat(); // [1, 2, 3, 4]

const words = ["JS", "DOM"];
words.flatMap(word => [word, word.toLowerCase()]);

const combined = first.concat(second);

Methodenketten lesbar halten

const visibleTitles = posts
  .filter(post => post.topic === "code")
  .sort((a, b) => b.date.localeCompare(a.date))
  .slice(0, 3)
  .map(post => post.title);

Array aus iterierbaren Werten

const nodes = document.querySelectorAll(".card");
const cards = Array.from(nodes);

const characters = [..."JavaScript"];

13. Set, Map, WeakSet und WeakMap

Set: eindeutige Werte

const topics = ["code", "code", "sailing"];
const uniqueTopics = [...new Set(topics)];

const selected = new Set();
selected.add("html");
selected.has("html"); // true
selected.delete("html");

Map: flexible Schlüssel

const postById = new Map();

for (const post of posts) {
  postById.set(post.id, post);
}

const found = postById.get(wantedId);
postById.has(wantedId);

Ein Objekt eignet sich gut für einfache Datensätze. Map ist besser, wenn Schlüssel beliebige Werte sein sollen oder häufig hinzugefügt und entfernt wird.

Über eine Map laufen

for (const [id, post] of postById) {
  console.log(id, post.title);
}

postById.size;

Schwache Sammlungen

17. this, Methoden und Funktionsbindung

this wird nicht danach bestimmt, wo eine normale Funktion geschrieben wurde, sondern wie sie aufgerufen wird. Arrow Functions besitzen kein eigenes this und übernehmen es aus ihrer Umgebung.

Methodenaufruf

const guide = {
  title: "JavaScript",
  printTitle() {
    console.log(this.title);
  }
};

guide.printTitle(); // "JavaScript"

Verlorener Kontext

const print = guide.printTitle;
// print(); // this ist nicht mehr guide

const boundPrint = guide.printTitle.bind(guide);
boundPrint();

call() und apply()

function describe(prefix) {
  return `${prefix}: ${this.title}`;
}

describe.call(guide, "Guide");
describe.apply(guide, ["Guide"]);

Arrow Function in Callbacks

class Timer {
  seconds = 0;

  start() {
    setInterval(() => {
      this.seconds += 1;
    }, 1000);
  }
}

Die Arrow Function übernimmt das this der Methode start().

Pragmatische Regel

Verwende Arrow Functions für kurze Callbacks und normale Methodensyntax für Objektmethoden. Nutze this nur, wenn objektgebundener Zustand tatsächlich einen Vorteil bringt.

22. Asynchrones JavaScript: Promises und async/await

Promise-Grundidee

Ein Promise repräsentiert einen Wert, der noch nicht vorliegt. Es ist pending, später entweder fulfilled oder rejected. 

loadPosts()
  .then(posts => {
    console.log(posts);
  })
  .catch(error => {
    console.error(error);
  })
  .finally(() => {
    console.log("Fertig");
  });

async/await

async function initialize() {
  try {
    const posts = await loadPosts();
    renderPosts(posts);
  } catch (error) {
    renderError(error);
  }
}

Eine async-Funktion liefert immer ein Promise zurück.

Unabhängige Arbeiten parallelisieren

const [posts, settings] = await Promise.all([
  loadPosts(),
  loadSettings()
]);

Schreibe unabhängige await-Aufrufe nicht unnötig untereinander. Das würde sie seriell ausführen.

Teilerfolge mit allSettled()

const results = await Promise.allSettled([
  loadWeather(),
  loadEvents(),
  loadPosts()
]);

for (const result of results) {
  if (result.status === "fulfilled") {
    console.log(result.value);
  } else {
    console.warn(result.reason);
  }
}

Das erste Ergebnis verwenden

const fastest = await Promise.race([
  loadFromPrimary(),
  loadFromMirror()
]);

race() reagiert auf das erste erfüllte oder abgelehnte Promise. any() wartet dagegen auf die erste erfolgreiche Erfüllung.

Verzögerung als Promise

function delay(milliseconds) {
  return new Promise(resolve => {
    setTimeout(resolve, milliseconds);
  });
}

await delay(500);

Kein await in forEach()

// Sequenziell
for (const url of urls) {
  const result = await fetch(url);
  console.log(result.status);
}


// Parallel
const results = await Promise.all(
  urls.map(url => fetch(url))
);

Top-Level Await im Modul

// Nur in einem ES-Modul:
const dataUrl = new URL("../json/posts.json", import.meta.url);

Praktisch, aber eine explizite init()-Funktion macht Initialisierung und Fehlerbehandlung oft verständlicher.
